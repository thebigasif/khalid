A place is a post with facts, read by position: 1 the kind of place, 2 the price level, 3 the opening hours, 4 the address. price_meter(fact): the price level as four marks, the ones up to the level in ink. A level written 1 to 4 draws round coins; one to four of the same sign, such as ££, draws that sign. Screen readers hear the level, not the marks. Any other value, such as Free, shows as written. place_rows(posts, level): each place as a listing row: a small square picture, the name, a dotted leader and the price meter on one line, then the kind and the opening hours. The name is the part of the title before a colon, so "Saggar Bakehouse: sourdough from the kiln" lists as "Saggar Bakehouse". A post without facts is left out. note_cards(posts, level): notes, posts without facts, as picture cards with their area and date. -#} {% from "image.html" import picture -%} {% macro price_meter(fact) -%} {% set value = fact.value | trim -%} {% set first = value[:1] -%} {% set signs = value | length <= 4 and (value | replace(first, "")) == "" and (first | lower) == (first | upper) and (first | trim("0123456789")) != "" -%} {% set level = value | int if value in ["1", "2", "3", "4"] else (value | length if signs else 0) -%} {% if level %}{{ t.price_level | replace("{level}", level | string) }}{% for mark in range(1, 5) %}{% if signs and mark <= level %}{{ first }}{% elif signs %}{{ first }}{% elif mark <= level %}{% else %}{% endif %}{% endfor %} {%- else %}{{ fact.label }}: {{ value }} {%- endif %} {%- endmacro %} {% macro place_key(post) -%} {% if post.facts[0] is defined or post.facts[2] is defined %}
