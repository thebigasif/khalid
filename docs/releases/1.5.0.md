# Khalid 1.5.0

Khalid 1.5.0 adds 38 templates, so there are 49 to choose from. Most have a live demo blog of their own at serpdad.com/khalid/demos/.

## Added

- **Eighteen templates based on Ghost's free themes (MIT):** Alto, Bulletin, Casper, Dawn, Digest, Dope, Ease, Edge, Edition, Episode, Headline, Journal, London, Ruby, Solo, Source, Taste and Wave. Each keeps its theme's look and credits it. Each one runs with no script on a post page, works light only, and uses Khalid's own sign-up, comments and search.
- **Twenty original templates** for kinds of site that had none:
  - Aperture for one photographer.
  - Atelier for a fashion lookbook.
  - Beacon for a charity.
  - Channel for a video creator.
  - Chapter for an author.
  - Encore for a band.
  - Fixture for a sports club.
  - Hub for a creator's link page.
  - Itinerary for travel diaries.
  - Lattice for science explainers.
  - Locale for a city guide.
  - Plinth for architecture.
  - Reel for film and TV reviews.
  - Research for a lab.
  - Respawn for games.
  - Summit for events.
  - Syllabus for an online course.
  - Ticker for a markets newsletter.
  - Versions for a product changelog.
  - Vital for health and wellness.
- **Post facts do more.** Many of the new templates read a post's facts: a session's time and room, a match's result, a release's format, a place's opening hours.

## Changed

- **A smaller binary.** The shared templates are carried compressed, as each template's own files already were. The binary stays under its size budget with 49 templates.
- **Demos refresh by themselves** after a change to a template.

To install or update, follow [docs/deploy.md](../deploy.md). The full list of changes is in [CHANGELOG.md](../../CHANGELOG.md).
