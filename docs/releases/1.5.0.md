# Khalid 1.5.0

Khalid 1.5.0 adds 20 templates of its own design, so there are 31 to choose from. Each has a live demo blog at serpdad.com/khalid/demos/.

## Added

- **Twenty new templates** for kinds of site that had none:
  - Aperture, for one photographer.
  - Atelier, for a fashion lookbook.
  - Beacon, for a charity.
  - Channel, for a video creator.
  - Chapter, for an author.
  - Encore, for a band.
  - Fixture, for a sports club.
  - Hub, for a creator's link page.
  - Itinerary, for travel diaries.
  - Lattice, for science explainers.
  - Locale, for a city guide.
  - Plinth, for architecture.
  - Reel, for film and TV reviews.
  - Research, for a lab.
  - Respawn, for games.
  - Summit, for events.
  - Syllabus, for an online course.
  - Ticker, for a markets newsletter.
  - Versions, for a product changelog.
  - Vital, for health and wellness.

  Each runs with no script on a post page and passes the same layout and speed checks as the others.
- **Post facts do more.** The new templates read a post's facts: a session's time and room, a match's result, a release's format, a place's opening hours.

## Changed

- **A smaller binary.** The shared templates are carried compressed, as each template's own files already were. The binary stays under its size budget.
- **Demos refresh by themselves** after a change to a template.

To install or update, follow [docs/deploy.md](../deploy.md). The full list of changes is in [CHANGELOG.md](../../CHANGELOG.md).
