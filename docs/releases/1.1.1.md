# Khalid 1.1.1

Khalid 1.1.1 is the release of everything in [Khalid 1.1.0](1.1.0.md): ten finished blog templates, pictures on every card, the fix for blogs under a folder such as `/blog/`, and the Deploy to Cloudflare button.

The 1.1.0 tag was made but never published. Its last release check started the demo blog, which lives under `/blog/`, and asked for its admin at `/admin/`. Since 1.1.0 that address moves to `/blog/admin/`, so the check stopped the release. The check now follows the move. Nothing else changed.

To install or update, follow [docs/deploy.md](../deploy.md). An existing blog changes nothing until you pick a template.
