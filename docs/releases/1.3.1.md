# Khalid 1.3.1

Khalid 1.3.1 fixes two things found on a live blog after 1.3.0. Nothing else changes.

## Fixed

- **The footer lines up again.** In the classic template, the footer was narrower than the rest of the page when the line length was set in characters, such as `measure = "68ch"`. It is now as wide as the header and the page.
- **Your own fonts load.** A blog that serves its own fonts showed the browser's fallback font instead, because Khalid never sent the font files. They now load, and browsers keep them for a year.
- **Smaller fonts from theme sync.** `khalid theme sync` now saves each font as one small file with only the letters most blogs use, often about 30 KB, instead of one large bold file. Run `khalid theme sync <your site>` again to get the smaller files.

To install or update, follow [docs/deploy.md](../deploy.md). The full list of changes is in [CHANGELOG.md](../../CHANGELOG.md).
