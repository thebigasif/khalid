# Khalid 1.0.1

This is a patch release of Khalid 1.0. It fixes a blog that lives under a folder of another site, and it adds looks, page parts and blocks that a site can switch on. A blog that changes nothing in its settings looks the same as on 1.0.0. Every change is listed in `CHANGELOG.md` under 1.0.1.

## Update from 1.0.0

Install 1.0.1 over 1.0.0, the same way you installed it, and restart `khalid serve`. Your site folder needs no change. Take a `khalid backup` first if you want a copy to go back to.

With the install script, add `--version v1.0.1`. With Docker, use `ghcr.io/thebigasif/khalid:1.0.1`. From source, check out the `v1.0.1` tag. `khalid --version` then prints `khalid 1.0.1`.

## Fixed: a blog under a folder now reaches its admin and APIs

A blog can live in a folder of a bigger website, such as `https://example.com/blog/`. That folder is the blog's mount. On 1.0.0 such a blog showed its posts, but its admin and its APIs answered at `/admin/` and `/api/`, outside the folder. The rule that `khalid init --stack` prints for your web server passes on only what is under `/blog/`, so the admin and the APIs could not be reached.

Now everything is under the folder:

- The admin is at `/blog/admin/`. An old `/admin/` address moves there.
- The Content API and the Admin API are at `/blog/api/`. They still answer at `/api/` for a program that reaches Khalid directly.
- Sign-in links, preview links, webhooks, the OpenAPI document and the newsletter form all name the folder.

A blog that is the whole site, at `/`, works exactly as before. `docs/deploy.md` lists every address for a blog under a folder.

## New: templates

A template is the look of your blog. Until now Khalid had one. Now `site.toml` takes a `[template]` table that names the look and sets its options. Without that table your site keeps today's look, now named classic, so nothing changes until you choose.

A template can switch on these parts, each one an option you set:

- **The main site's logo in the header**, and its icon in the browser tab when theme sync found one. Theme sync is how Khalid copies your main site's colours and fonts.
- **Breadcrumbs**, the trail of links from the home page to the post. A post with a category also gets that category in its breadcrumb schema, the hidden labels search engines read.
- **A post's subtitle and why it was updated.**
- **Cards for lists of posts**, in five shapes, with reading time and the author's role.
- **A featured post above lists, editor's picks and numbered page links.**
- **Related posts** in five layouts, and **a post's contents** in five places.
- **A call to action.** Set one in `site.toml` under `[template.cta]`, with a label, a link and a short note. A template shows it as a band after each post or on the front page, or as a button in the header.
- **Footer columns.** `[[nav.footer_groups]]` sets columns of footer links, each under its own heading. A column can be for one language only.
- **Share links** under a post's title, after it, or both. They are plain links to each network's own share page and an email link: no script, and nothing loaded from the networks.
- **A newsletter sign-up form** after each post, on the front page, or both, on a blog that takes sign-ups.

`docs/templates.md` lists every option.

## New: blocks

A block is a part of a post written with a short marker in markdown, such as a tip or an FAQ. Every block now has its own look, and there are new ones:

- **Columns.** `::::columns` around two to four `:::column{title="..."}` cards sets them side by side, and stacks them on a phone.
- **Pull quote.** `:::pullquote{by="..."}` sets a short line large, with who said it.
- **Pros and cons.** `:::proscons` shows a `+` list beside a `-` list.
- **Folding tables.** `:::table{fold=8}` shows the first eight rows and a line that opens the rest.
- **Call to action.** `::cta` places your `[template.cta]` anywhere in a post or page.
- **Three new callout kinds**: `summary` for key takeaways, `read` for further reading and `stat` for one number worth remembering.

Every one of them reads in full with scripts off. Two small fixes came with the new looks: the hidden field that catches spam on forms no longer shows to readers, and comments in code are coloured.

## Under the hood

Khalid now reads settings files with toml 1.1 and XML files, such as sitemaps and WordPress exports, with roxmltree 0.21. You will see no change, except that a very deeply nested XML file no longer crashes the reader.

## Still checked after launch

The checks listed in the 1.0.0 notes, which need a real server, an outside account or a person, are still in progress. We will report what they find in a later release's notes.

## Checking a download

Each release has a `SHA256SUMS` file. The install script checks against it for you. By hand, run `sha256sum -c SHA256SUMS --ignore-missing` in the folder that holds the download.
