# Khalid 1.4.0

Khalid 1.4.0 gives every template a designed look of its own, with a live demo blog for each, and makes the binary smaller so many more templates fit.

## Changed

- **Ten redesigned templates.** Atlas, Almanac, Compass, Folio, Harbor, Keystone, Ledger, Meridian, Wire and Workbench each have a signature look: a map-grid masthead, numbered stops, a release log, a score panel, a recipe strip and more. Classic, the look every blog starts with, has a wider frame and a large lead story.
- **Each template has a live demo publication** with real-looking posts and free photos, at serpdad.com/khalid/demos/.
- **A smaller binary.** Every template's stylesheet and page files are carried compressed in one archive. Pictures keep one fallback copy instead of one per size, so a site's pictures take about half the disk space.
- **Harbor is a food and recipe blog**, and the demo gallery groups it that way.

## Added

- **Facts on a post.** A post can list up to four short facts, such as `Serves: 4` or `Client: Calder Street Library`, and templates show them on its card and page.
- **A Ghost-compatible Content API.** A front end built on Ghost's Content API can read a Khalid blog.
- **Image downloads on import.** `khalid import --download-images` copies the pictures an imported post shows into the post's own folder.
- **`khalid init --template <name>`** starts a new blog in any built-in template.

## Fixed

- **The first picture on a post list loads at once**, so the large picture at the top no longer shows as an empty box first.
- **Workbench on a phone** no longer scrolls sideways by one pixel.
- **A post shows its contents once**, author photos stay round in every template, and Classic keeps a comfortable line on every computer.
- **The Content API lists tags and pages** on a running site, and commands work inside the blog folder without `--site`.

To install or update, follow [docs/deploy.md](../deploy.md). The full list of changes is in [CHANGELOG.md](../../CHANGELOG.md).
