# Khalid 1.3.2

Khalid 1.3.2 fixes what a live blog on 1.3.1 showed when it was tested in Chrome, Firefox and Safari on a phone, a tablet and a desktop.

## Fixed

- **Pages lay out cleanly in every template.** Pictures and tables no longer run under the side contents list, list markers no longer cover words, folded tables no longer break words on a phone, and no home page scrolls sideways. The Contents button sits at the start of a post instead of floating over the text.
- **Videos play in Safari.** Videos, sound files and CSV downloads go out with their real type, and Khalid sends a video in parts, as Safari needs. The video embed no longer causes an error in Safari.
- **Clearer list pages.** Tag pages say "Tag", series pages number their parts, glossary terms link back to the glossary and to related terms and posts, and the sitemap tells categories and tags apart.
- **Better search results.** Text from separate blocks no longer runs together, and the Search button stays beside the box in Safari.
- **Fairer writing checks.** The short-answer check reads only the first paragraph, and the statistics check warns only on real statistics.
- **Wikilinks in tables.** `[[slug|words]]` works inside a table cell.
- **Settings without a restart.** `khalid serve` applies a saved `site.toml`, routes or theme file straight away.
- **Pictures on every home page card**, including the topic tabs and the video and podcast rows.

## Added

- **A feed for every category and channel**, in RSS, Atom and JSON, linked from the page head.
- **Keystone breadcrumbs, the updated note, and up to ten related posts.**
- **A Sitemap line from `khalid init --stack`** for the main site's robots.txt.
- **A layout check in three browsers** that runs before every release, so faults like these are caught first.

To install or update, follow [docs/deploy.md](../deploy.md). The full list of changes is in [CHANGELOG.md](../../CHANGELOG.md).
