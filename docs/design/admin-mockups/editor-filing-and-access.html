Planning a topic cluster in an afternoon

A topic cluster is a group of posts on one subject, with one main post that the others link to. Here is how to plan one in an afternoon, with nothing but a list of questions your readers ask.

Start with the questions. Write each on its own line, then group the ones that share an answer.
