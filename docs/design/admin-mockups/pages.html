Pages

A page is part of your site that is not a post, such as About or Contact. It has no date and no author, and stays out of the post lists and feeds. Each page is a file in your site folder, so git keeps its history.

Add a page

As readers see it at the top of the page.
The last part of the page's address. Lowercase words joined by hyphens, such as about.
The page's language, such as de. Leave it empty for the blog's main one.
One or two sentences search engines show under the title. Optional.
What the page says, in markdown.

A new page is live as soon as you add it.

Opening a page

Edit opens the page on its own screen: "This is the English page at the address about. Saving puts your change live at once." Below that sit its title, description and text, a Save page button, and "Delete this page", which says first that links to the page will lead nowhere.
