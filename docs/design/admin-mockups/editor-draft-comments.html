Comments on a draft

Staff can leave each other notes on a post before it goes live. A note can be about the whole post or about one part of the text, and others can answer it. Readers never see them.

3. Starting a thread

A site built to files keeps no comments. Adding one there says why, in the server's own words, and the text you typed stays in the box.
