Breadcrumbs

Breadcrumbs are the trail of links above a page, such as Home / Technical SEO / Choosing anchor text. Google shows the same trail in search results.

The mark between two steps. Leave it empty for the default: /
Such as Home. Leave it empty to use the blog's name.
Shown on tag, category, author and date pages, such as Archives for. Leave it empty for none.
Shown on the search page, such as You searched for. Leave it empty for none.

The last step is the page the reader is on.

Site search

Bots fill a blog's search page with long or spam searches, so the page shows their words and links. Each filter here refuses such a search before anything is looked up.

A longer search is refused. 50 by default. 0 sets no limit.
Letters, digits and punctuation are always allowed.
A search with a link, markup, a spam domain such as .xyz, or one character six times in a row.

Files for AI tools

Two files help AI tools and search engines read the whole blog at once, instead of page by page.

llms.txt

A short guide to the blog for AI tools: what it covers and its main pages.
Shown after the tagline, such as who writes the blog and how to cite it. Leave it empty for none.
One path per line, listed first, such as /about/.
One path per line. Every page below a path is left out too, such as /tag/.

Whole-blog schema

All the blog's structured data in one file. Structured data is the description of a page that search engines read, such as its author and date.
Lighthouse then marks robots.txt as invalid, which lowers the SEO score of every page.

Local business

For a shop, office or clinic. site.toml lists 2 locations: Mill Lane Dental and Kirkgate Dental.

Every location's address and opening hours on one page.
A map file with a pin for each location that has a point on the map. Search engines find it in the sitemap.
