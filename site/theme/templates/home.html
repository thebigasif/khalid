Why Khalid

The problem it solves

Most blogs lose readers in quiet ways. Khalid puts the checks before the post goes live, and builds the SEO in.

A blog without checks

  • {{ mark(cross) }} A post goes out with no description.
  • {{ mark(cross) }} A link breaks when a page moves.

How it works

Write, check, publish

  1. Write

    Write in the web editor, or as text files in any editor you like. Every post is a file you own.

    content/en/posts/my-first-post.md

  2. Check

    The writing checks read the post like a careful editor, and say what to fix and why in plain words.

    khalid lint

  3. Publish

    Khalid writes the pages, the SEO, the sitemaps and the feeds, as plain files or from a small server.

    khalid build
