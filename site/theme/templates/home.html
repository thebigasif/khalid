{{ page.title }}: a blog that checks every post before it goes live

Khalid is an open-source blog engine you add to the website you already have. It is one small program. Every post is a text file. It writes the SEO for you, and it will not publish a post with the mistakes that hurt it in search.

Start a blog or see the demo blog.

Who it is for

Businesses that want a blog beside their main website, whatever that site is built with. Small marketing teams, agencies, founders and newsletter writers who want posts that search engines and AI tools can find.

You do not need to be technical to write. The admin is a web editor. People who like the command line and AI agents can use the same features there.

See who uses Khalid, and how.

The problem it solves

Most blogs lose readers in quiet ways. A post goes out with no description. A link breaks when a page moves. Search tools need a plugin, then another, and each one needs updates.

Khalid puts the checks before the post goes live, and builds the SEO in. A careful editor reads every post, and nothing extra needs installing.

See how the writing checks work.

What you get

  • Writing checks that stop serious mistakes and explain every fix. Writing checks
  • SEO and AI search built in: tags, structured data, sitemaps, feeds and files for AI tools. SEO and AI search
  • A web editor with blocks, versions and roles for your team. The editor
  • Drafts, previews and scheduling, so posts go live when they are ready. Publishing
  • A newsletter and members-only posts, with your list on your own site. Newsletter
  • Comments and forms that work with scripts off. Comments and forms
  • Analytics without cookies, including readers sent by AI tools. Analytics
  • Imports from WordPress, Ghost, Medium, Substack and markdown. Moving your blog
  • APIs, an SDK and an MCP server for your tools and AI agents. APIs
  • Fast, light pages that need no script, on a server or as plain files. Hosting and speed
  • Backups in one file, a safe restore and undo for mistakes. Backups
  • Your brand's look copied from your website, in any language. Theme sync

See every feature or browse the templates.

Three ways to start

  1. The install script. One line on Linux or a Mac puts Khalid on your computer. Windows has a download.
  2. Docker. Each release publishes an image, so you run a blog without building anything.
  3. The Deploy to Cloudflare button. Cloudflare copies a small ready blog into your GitHub account and puts it online on its free plan.

See the steps for each way, or compare Khalid with WordPress, Ghost and Webflow first.

Open, and checked in public

Khalid is open source under the AGPL licence. Its code, tests and every decision are public on GitHub. This website is built with Khalid and passes its own checks.
