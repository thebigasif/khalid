- Ledger, the text-led template for studies and long how-tos, has a new design. Its front page opens with the blog's name set very large over a double rule. The newest post leads, the rest follow as numbered rows split by thin lines (no boxes), and on a wide screen the topics stand in a numbered index beside them. Post titles run wide over a reading column of about 70 characters, with the contents beside the text on a wide screen. Headings use a heavy system sans and the text a sturdy serif. The frame is 75rem. Colours and fonts come only from the tokens, so a synced theme still recolours it all.
