Added
- The editor's block menu now offers nine more blocks the blog already reads from files: book, chart, course, dataset, event, location, privacy facts, folding table and key takeaways. Each opens a short form for its details, and a post that holds one now opens in the rich-text view instead of as plain markdown.
- The video block's form asks for a search thumbnail and the day the video was first published, and the embed block's form asks for the frame's height and the same day.
- A chart's kind and an event's status are picked from a list, so a writer cannot type a word the blog refuses.
