Added
- A Tags and categories screen in the admin, under Site. It lists every tag in every language with how many posts have it. Rename changes the tag in every post at once, and a name another tag has joins the two. Remove takes the tag off every post. Each change says how many posts change before it asks, and refuses when a post changed after the list was read.
- The same screen lists the site's categories with their name in each language and how many posts are in each. An owner can add a category with a name in each of the site's languages, rename one (posts keep it, and its short name and address stay), and delete one that no post is in.
