Changed
- The `site.changed` webhook now fires once `khalid serve` has put saved settings in use, for a change to `site.toml`, `routes.toml` or any file under `theme/`. Its body lists the changed files under `files`, and `restart_needed` is `true` only when a change waits for the next start. A `site.toml` saved with only comments changed fires nothing. The webhook docs now say which command fires each event, and that the `.scheduled` events of pages, glossary terms, case studies and changelog entries do not fire yet, because those entries cannot be given a publish time (KH-API-3).
