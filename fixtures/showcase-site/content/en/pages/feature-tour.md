This blog, Larkspur Ledger, is the demo of [Khalid](https://github.com/thebigasif/khalid), an open-source blog engine. Larkspur Studio, its people and its benchmark are made up. The advice is real.

Each line below names one feature and links to a page where you can see it. Open any link, look, and come back.

## What you cannot see on a page

- **A linter that refuses a weak post:** every post here passes `khalid lint` with no warning. It checks titles, descriptions, links, sources for numbers, glossary links, answers under question headings and more.
- **A site audit:** the built blog passes `khalid audit`, the same kinds of checks the big SEO tools run.
- **An admin, an API and command-line tools:** the editor offers every block on this page. See [Khalid on GitHub](https://github.com/thebigasif/khalid) to run your own.
