---
term: XML sitemap
slug: xml-sitemap
---

An XML sitemap is a file that lists the addresses on a site you want search engines to find, often with the date each one last changed. It helps new and updated pages get found sooner. It does not make a page rank, and listing a page does not force it into the index. Our post on [XML sitemaps for blogs](/blog/xml-sitemaps/) explains what belongs in one.
