This is the fiftieth issue of The Proof Sheet, and every line of its first page was set by hand. We set it in the shop where the letter began: a railway arch near the canal, a hand press older than any of us and a wall of type cases. Trains run overhead every twenty minutes. The press does not mind.

## Back where it began

The first issues were printed here before they were ever sent by email. Maren set the type on Wednesday nights and pulled a proof sheet to check it, which is how the letter got its name. The [first printed issue](/blog/why-this-letter-is-printed/) explains why we still print a small run each week, even now that most of you read it on a phone.

The shop belongs to a printer called Ada, who has run it for thirty years. She prints posters, wedding invitations and the menus of three cafes on the high street. She lets us use the press on quiet evenings in return for help with the cleaning, which is a fair trade. Clean type prints well, and dirty type prints badly.

## The composing stick

The tool this week is the composing stick, the small metal tray a compositor holds in one hand while picking letters from the case with the other. Each line is built letter by letter, upside down and back to front, then tightened so nothing moves. You can read about the [composing stick](https://en.wikipedia.org/wiki/Composing_stick) and the cases it fills from.

A good compositor sets about a line a minute. Maren sets one in three, and she has been doing it for years. Speed is not the point. The point is that every space between every word is a choice you can see and change.

## Set by hand, fifty times

Fifty issues set by hand is roughly six thousand lines. Ada worked it out on the back of an envelope and then asked whether we had considered a computer. We had. We still print the first page this way, because a letter that comes off a press feels like a letter, not a feed.

## Letters

Several of you asked where to find a press of your own. Start with your local college or library: many have one in a store room that nobody has used in years. Ask nicely, offer to clean it, and bring biscuits. Last week's issue on [lampwork glass](/blog/glass-heat-and-breath/) has the same advice for torches.
