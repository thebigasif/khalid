I have filled a notebook roughly every three months since 2009, so there are about seventy of them on the shelf now. People who see the shelf ask how I find anything. The answer is a notebook system so simple it barely counts as one.

## Number everything

Every notebook gets a number on its spine, in white ink, in the order I start them. Every page gets a number in its top corner. If the paper is not numbered already, I number it on the first evening, all at once, while the notebook is still new.

With both numbers, any page in seventeen years has a short address, such as 54.112. That means notebook 54, page 112.

## Date every entry

Each morning's writing starts with the date in the margin. That is all. I add no title and no heading. The date is enough to tell one day from the next. It also means I can work out roughly where something is if I remember when it happened.

## The index at the back of the notebook system

The last four pages of each notebook are the index. When I write something I think I will want again, such as an idea for an essay, a good quote or a name, I add one line to the index: a few words and the page number. It takes ten seconds.

When a notebook is full, I copy its index lines into one long file on the computer, with the notebook number in front. Searching that one file finds almost anything.

## What I leave out

- No colours or codes for different kinds of entry.
- No separate notebooks for separate subjects, except one [commonplace book](/blog/commonplace-book/) for other people's sentences.
- No rule about how much to write each day.

Every notebook system I tried with more rules lasted about a month. This one has lasted seventeen years, because it asks very little.

## Try it

You need nothing new. Number the pages of the notebook you have, date each entry and save the last pages for an index.
