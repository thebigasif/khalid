Mossboard has ten new keyboard shortcuts, mostly for moving and editing cards without the mouse. Press **?** anywhere to see every one of them in one list.

## Every keyboard shortcut

| Key | What it does |
|---|---|
| N | Add a card to the list you are in |
| E | Edit the open card's title |
| D | Set the open card's due date |
| L | Add a label |
| M | Add yourself to the card |
| A | Archive the open card |
| Shift and arrow keys | Move the card to the next or previous list |
| Space | Open or close the card under the pointer |
| / | Search all boards |
| C | Switch to the calendar view |
| ? | Show every shortcut |

## Why we added them

People who spend all day in Mossboard asked for faster ways to work, and many of them prefer the keyboard. Moving a card between lists took several clicks. With a [keyboard shortcut](https://en.wikipedia.org/wiki/Keyboard_shortcut) it is one key press.

## Shortcuts that stay out of your way

They never fire while you type in a text box, so writing a comment with the letter N will not add a card. If a key clashes with your browser or a screen reader, turn them off under **Settings**, then **Keyboard**. You can also turn off single-letter keys alone and keep the ones with Shift.

## Where the keyboard shortcuts lead

Search moved to the slash key, the same key many sites use; the [better card search](/blog/card-search-comments/) of version 3.3 opens from it. The A key archives a card, which became the safe way to clear a board in 3.1 with [archived cards](/blog/archived-cards/). On a tablet the keyboard is often put away, so the [fix for dragging cards](/blog/dragging-cards-tablets/) in 3.3 matters more there. On a large board every key answers at once, since the [faster board loading](/blog/faster-board-loading/) of 3.4.

Teams that connect Mossboard to their own tools can use [webhooks](/blog/webhooks/) to act on each move.
