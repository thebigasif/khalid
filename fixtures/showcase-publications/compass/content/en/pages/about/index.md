Northbound is an evening coding school for adults in Kestrel Bay. Most of our students have never written a line of code. They are nurses, bus drivers, shop owners and retired engineers, and they come to us to build a small website of their own or to find out whether a new career might suit them.

This blog is our free learning path. It holds the same guides we hand out in class, in the order we teach them, so anyone can follow it from home.

## The path

The guides sit in four stops. Take them in order if you are starting from nothing.

1. **[Start here](/blog/category/start-here/):** how to begin, your first program, reading errors and how to practise.
2. **[The web](/blog/category/the-web/):** how a page reaches your screen, then HTML, CSS and a little JavaScript.
3. **[Tools](/blog/category/tools/):** the terminal, a code editor, Git and the browser's developer tools.
4. **[Your first project](/blog/category/first-project/):** plan, build, adapt for phones and put online one small website of your own.

The best first guide is [how to start coding as an adult](/blog/start-coding/).

## How we test every guide

Before a guide goes live, a second teacher reads it and the guide names them. Then a student from the current evening group follows it from start to finish on their own computer while a teacher watches without helping. Wherever they get stuck, we rewrite. Every code example is pasted into a blank file and run before we publish it.
