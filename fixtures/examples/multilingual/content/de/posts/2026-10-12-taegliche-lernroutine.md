Eine tägliche Lernroutine ist eine kleine, feste Zeit an jedem Tag, in der Sie an Ihrer Sprache arbeiten. Sie zählt mehr als jede Methode. Eine Methode, die Sie jeden Tag nutzen, schlägt eine bessere, die Sie nur nutzen, wenn Ihnen danach ist. Schwer ist nicht der Anfang. Schwer ist der zweite Monat, wenn die erste Begeisterung verflogen ist.

## Die tägliche Lernroutine klein halten

Wählen Sie eine Zeit, die so kurz ist, dass Sie nicht mit sich verhandeln: eine Viertelstunde oder sogar zehn Minuten. An guten Tagen machen Sie mehr. An schlechten Tagen schaffen Sie trotzdem das Minimum, und die Gewohnheit überlebt.

## An etwas knüpfen, das Sie ohnehin tun

Hängen Sie das Lernen an einen Moment, den es jeden Tag gibt: den ersten Kaffee, die Fahrt im Bus, den Spaziergang mit dem Hund. „Nachdem ich mir Kaffee eingeschenkt habe, mache ich meine Karteikarten“ ist ein Plan. „Ich lerne morgens“ ist ein Wunsch.

## Die Woche planen, nicht nur den Tag

Geben Sie jedem Wochentag eine Art des Übens. Dann verlieren Sie keine Zeit mit der Entscheidung:

| Tag | Übung |
|---|---|
| Montag | Karten mit [verteilter Wiederholung](/blog/de/verteilte-wiederholung/) |
| Dienstag | Ein Kapitel einer [vereinfachten Lektüre](/blog/de/vereinfachte-lektueren/) lesen |
| Mittwoch | Karten wiederholen |
| Donnerstag | Mit einem Partner sprechen oder eine Aufnahme mitsprechen |
| Freitag | Karten wiederholen |
| Wochenende | Etwas, das Spaß macht: ein Film, ein Lied, ein Rezept in der Sprache |

## Sichtbar festhalten

Hängen Sie einen Kalender an die Wand und kreuzen Sie jeden Tag an, an dem Sie lernen. Eine Kette von Kreuzen reißt man ungern ab. Verpassen Sie einen Tag, dann verpassen Sie nicht auch den zweiten.

:::callout{kind=note}
Halten Sie auch fest, was Sie lernen. Schreiben Sie einmal im Monat eine Sache auf, die Sie jetzt können und vorher nicht, etwa [falsche Freunde erkennen](/blog/de/falsche-freunde/) oder einem Podcast folgen.
:::

## Fortschritt am Können messen

Die Stufen von A1 bis C2 im [Gemeinsamen Europäischen Referenzrahmen](https://www.coe.int/en/web/common-european-framework-reference-languages) beschreiben, was Lernende auf jeder Stufe können. Lesen Sie diese Beschreibungen alle paar Monate. So sehen Sie, wie weit Ihre tägliche Lernroutine Sie gebracht hat.
